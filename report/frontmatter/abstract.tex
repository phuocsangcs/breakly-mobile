\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Breakly is a mobile application that helps students and desk-based workers
take intentional, time-boxed micro-breaks. The project addresses the
difficulty of interrupting prolonged screen use, choosing a suitable short
activity, and returning to work without unnecessary configuration.

This specification defines the stakeholders, personas, elicitation plan,
functional requirements, and MoSCoW priorities for the Breakly MVP. It also
sets measurable mobile constraints for performance, offline behaviour,
security, permissions, accessibility, battery, and network usage. The
proposed design uses a mobile-first Clean Architecture with MVVM, local
storage for the core offline flow, and optional backend synchronisation.
The report further specifies the data model, API contract, user flows,
hi-fi mockup requirements, and traceability from requirements to screens,
architecture components, and verification evidence.
