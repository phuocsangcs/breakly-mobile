\subsection{API Contract}
\label{sec:api-contract}

The backend exposes a versioned REST API under \texttt{/api/v1}. Requests and
responses use JSON, and the OpenAPI document and Swagger UI are generated by
springdoc from the controllers. Endpoints marked \textit{public} need no
token; all others need the header \texttt{Authorization: Bearer} with a valid
access token. A user can only read and change their own data, because the user
ID is always taken from the verified token and never from the request.

\paragraph{Error format.}
Every failing request returns the same JSON object with \texttt{code},
\texttt{message}, optional \texttt{details} (for example the invalid fields)
and \texttt{timestamp}. The app maps the codes to its error states
(Table~\ref{tab:api-errors}).
