\paragraph{Offline, Synchronisation, and Failure Behaviour}
\label{sec:offline-behaviour}

The core break flow must work without an internet connection. Preferences,
activity content bundled with the app, and session history are available
locally. If optional remote content cannot be loaded, the app shows cached
content and an explicit offline state rather than a blank screen. A future
synchronisation layer must use conflict-safe updates and report failures
without discarding local sessions.

\paragraph{Permissions, Platforms, Battery, and Network}
\label{sec:mobile-constraints}

The MVP targets Android and iOS versions supported by the selected Expo and
React Native release. Notification permission is optional and requested in
context. Location, contacts, microphone, and camera permissions are not
required for the core experience. The timer uses timestamps rather than a
busy polling loop, and background work is limited to scheduled notifications
to reduce battery consumption. Network access is optional for the MVP and
must tolerate latency, timeouts, and temporary disconnection.
