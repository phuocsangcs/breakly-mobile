\chapter{Demonstration}
\label{chap:demonstration}

\section{Basic Flow}
\label{sec:basic-flow}

The basic demonstration flow is: open Breakly, review the suggested activity,
start a break, follow the timer, complete or skip the break, and view the
result.

\section{Break Configuration Flow}
\label{sec:break-configuration-flow}

This flow demonstrates changing the duration and activity preferences,
starting a customised break, and confirming that the selected configuration
is used by the timer.
